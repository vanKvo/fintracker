The Transactions tab lists every transaction from your statements and manual entries. It is where you review imported rows, fix categories and decide what counts.

## Pending and approved transactions

Transactions imported from a statement start as **pending**. A pending transaction is not counted in your Dashboard, budgets or reports until you approve it. Approved transactions are counted.

Review each pending row, correct the category if needed, then approve it. Approving is how you tell FinTracker "this row is correct".

## Change a category

Each transaction has a category. FinTracker suggests one from the merchant name or your bank's label. Transactions it cannot place are shown as Uncategorized and highlighted.

To change a category, edit it on the row and choose from the system categories and your own active custom categories. The bank's original label stays visible, so you can see why a suggestion was made.

If a category was removed while a transaction was still pending, the row is highlighted with "This category is no longer available". Pick another category, then approve.

## Approve a transaction

Choose Approve on a pending row. To approve many rows at once, tick their checkboxes and choose Approve in the bulk actions bar. Rows with an unavailable category stay pending while the others are approved.

You can also approve every pending transaction of one statement from the Statements tab.

## Exclude a transaction

Exclude hides a transaction from budgets and reports without deleting it. Use it for rows you do not want counted, such as a one-off or a duplicate. You can bring it back by turning Exclude off.

## Split a transaction

Split divides one imported row into several smaller rows so each part can have its own category. For example, split a single store purchase into groceries and household. Open the row's Split option, enter the amounts and categories, and save.

## Add tags

Tags are free labels you attach to transactions, such as "vacation". Add a tag from a row, or select several rows and add one tag to all of them.

## Add a transaction by hand

To record a cash purchase, choose Add Transaction. Enter the date, merchant, amount, category and account. Manual transactions can be edited and deleted.

## Delete a transaction

Only transactions you added by hand can be deleted. Imported rows cannot be deleted one by one. Exclude them instead, or delete the whole statement they came from in the Statements tab.

## Search and filter

Use the filter bar to narrow the list by merchant text, date range, category, account, tag and status. The list shows the total for what you have filtered.

## Transaction types

Each transaction is one of five types: expense, income, refund, transfer or adjustment. A refund reduces spending in its category. A transfer between your own accounts is not counted as spending or income. See "Key concepts" for how each type is counted.
