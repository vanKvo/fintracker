# FinTracker Analytics - Open Chat

## 1: In-App Open Chat Support

### Problem
Users' money questions are specific and change all the time ("Why was October higher?", "Can I afford this trip?", "What do I spend on coffee?"). Static data can't answer every question, so users export to spreadsheets to find answers for themselves, use another app or give up.

### Why AI 
A conversational assistant can answer free-form questions from the user's own data and pull together several views in one answer.

### Requested Changes


### Constraints:
Each user sees only their own data.
Answers stay within budgeting and are based on facts the system computed.
Cost per user is capped through tier limits and rate limits.
Every conversation can be audited.
Conversations are used for improving the AI only with the user's consent.
