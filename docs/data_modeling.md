# FinTracker Master Database Schema & Architecture Blueprint

## 1. User Profile Service (DynamoDB)
**Table Name:** `FinTracker_UserProfile`
**Billing Mode:** PAY_PER_REQUEST (On-Demand)
**Design Pattern:** Single-Table Design

| Entity | Partition Key (PK) | Sort Key (SK) | Key Attributes | Notes / Rules |
| :--- | :--- | :--- | :--- | :--- |
| **User Profile** | `USER#<user_id>` | `PROFILE` | `email`, `first_name`, `last_name`, `phone_number`, `sub_tier`, `created_at` | `user_id` is a UUID generated by Cognito. |
| **User Settings**| `USER#<user_id>` | `SETTINGS` | `currency`, `timezone`, `mfa_enable`, `notification_prefs` | Separated from profile to keep profile reads extremely lightweight. |
| **Fin. Goals** | `USER#<user_id>` | `GOAL#<goal_id>` | `name`, `target_amount`, `deadline` | Fetched via `begins_with(SK, 'GOAL#')` |

## 2. Data Pipeline Service (DynamoDB)
**Table Name:** `FinTracker_DataPipeline`
**Billing Mode:** PAY_PER_REQUEST (On-Demand)
**Design Pattern:** Single-Table Design with TTL

| Entity | Partition Key (PK) | Sort Key (SK) | Key Attributes | Notes / Rules |
| :--- | :--- | :--- | :--- | :--- |
| **Merchant Registry**| `merchant_name` (Lowercased) | `DETAILS` | `category`, `sub_category`, `confidence` | Prevents redundant Amazon Comprehend calls. Bootstrapped with seed map. |
| **Job Tracker** | `JOB#<step_func_id>`| `METADATA` | `user_id`, `status`, `error`, `ttl` | **TTL Enabled** (7 days). Tracks async pipeline states. |
| **Websocket Conn**| `WS#<connection_id>` | `USER#<user_id>` | `created_at`, `ttl` | Maps API Gateway WebSocket connections to users for UI push notifications. |
